# Changelog

## 0.2.0 — 2026-09-01

### Added
- Full BAYNORA Arabic-first visual system and responsive storefront shell.
- Dynamic Salla navigation, search, account, cart and mobile bottom navigation.
- Branded home, product, catalog, cart, customer, order, blog, brand, loyalty, testimonials, content and thank-you views.
- Merchant-editable homepage copy through `twilight.json` settings.
- Salla-native product options, add-to-cart, quick order, gifting, coupons, cart summary and customer web components.
- GitHub Actions validation for Twilight metadata, required routes, production build and built asset size.

### Fixed
- Added current Twilight build dependency `glob` required by ThemeWatcher.
- Hardened optional order data and custom profile image fields.
- Improved product form semantics and cart note/tax handling.
